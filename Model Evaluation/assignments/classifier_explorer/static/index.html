Each fitted degree adds a point. Train metrics are reweighted to the natural fraud rate so they are comparable with test. A widening gap between train and test means the model is overfitting.

Honesty note: the threshold here is tuned on the same test set it is scored on. That is fine for exploring, but it leaks: in a real project you would pick the threshold on a validation split and report performance on a test set you never looked at.
