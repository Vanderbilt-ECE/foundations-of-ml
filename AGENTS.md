# Repository instructions

- The root `grades/` folder and all its contents must always stay local. Never stage, commit, push, upload, or publish them. Keep `/grades/` in `.gitignore`; do not bypass it with `git add -f`.
- When opening email, preserve its original read/unread status. If opening an unread message marks it read, mark it unread again afterward so the user can distinguish messages they have personally read.
