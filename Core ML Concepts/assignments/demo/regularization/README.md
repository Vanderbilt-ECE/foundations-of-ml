# Regularization demo

A minimal comparison of ordinary linear regression, ridge regression (L2), and lasso regression (L1) on scikit-learn's diabetes dataset.

## Run

```bash
uv run regularization_demo.py
```

The script opens two interactive Plotly charts:

- test-set R² for each model;
- the learned coefficient values for each feature.

Ridge and Lasso are placed in a `StandardScaler` pipeline because regularization depends on feature scale.

## Synthetic polynomial demo

```bash
uv run synthetic_regularization_demo.py
```

This demo fits a degree-10 polynomial to noisy data generated by a cubic. It contrasts the wiggly unregularized fit with Ridge's coefficient shrinkage and Lasso's exact-zero coefficients.

## Cross-validated synthetic demo

```bash
uv run synthetic_regularization_cv_demo.py
```

This version uses five-fold cross-validation to select the Ridge and Lasso penalty strengths before plotting the fitted curves and coefficients.

## Bias-variance demo

```bash
uv run bias_variance_demo.py
```

This script resamples 500 noisy training sets from the same cubic function. For polynomial degrees 1 through 5, it estimates and plots prediction bias² and variance across the full input range.

## Regression-loss demo

```bash
uv run regression_loss_demo.py
```

This demo defines MSE and MAE as custom lambda losses, then fits polynomial weights with batch gradient descent. Deliberate outliers reveal why squared loss is more sensitive to large residuals than absolute loss.
